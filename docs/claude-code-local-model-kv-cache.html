Claude Code + Local Model + KV Cache

让本地后端（llama.cpp）的提示词前缀更稳定，提升 KV cache 命中率，减少重复 prefill。

核心问题

Claude Code 每次请求会注入动态变化的 metadata 或 git context，导致 KV cache miss，迫使后端重新 prefill 大段 system prompt。

解决思路

通过 --exclude-dynamic-system-prompt-sections 和 --settings 将动态信息移出 system prompt，使其在多轮请求间保持稳定。

1
启动 llama-server 配置 KV cache 参数
2
启动 Claude Code 禁用动态 system prompt
3
验证效果 对比首次与后续请求

How it works

KV Cache 命中原理

动态信息移出 system prompt 后，llama-server 可复用已缓存的 KV 数据，大幅减少重复计算。

User Message 动态内容
+
Static Prefix 稳定不变

llama-server startup 
# 启动 llama-server 并配置 KV cache
/path/to/llama-server \
  --model /path/to/your-model.gguf \
  --jinja \
  --reasoning auto \
  --threads 12 \
  --n-gpu-layers 99 \
  --flash-attn on \
  --mlock \
  --cache-type-k q8_0 \
  --cache-type-v q8_0 \
  --cache-ram 24576 \
  --ctx-checkpoints 128 \
  --checkpoint-every-n-tokens 1024 \
  --slot-prompt-similarity 0.01 \
  --host 127.0.0.1 \
  --port 8080 \
  --parallel 1 \
  --cont-batching \
  --metrics \
  --slots
claude-code startup 
# 启动 Claude Code 连接到本地后端
ANTHROPIC_BASE_URL=http://127.0.0.1:8080 \
ANTHROPIC_API_KEY=no-key \
ANTHROPIC_MODEL=your-model.gguf \
CLAUDE_CODE_ATTRIBUTION_HEADER=0 \
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1 \
DISABLE_TELEMETRY=1 \
DISABLE_ERROR_REPORTING=1 \
claude --bare \
  --model your-model.gguf \
  --dangerously-skip-permissions \
  --exclude-dynamic-system-prompt-sections \
  --settings '{"includeGitInstructions":false}' \
  --allowedTools "WebFetch,Read,Edit,Write,Bash(curl:*)"

Configuration

核心参数说明

llama-server 关键参数

参数 说明
--flash-attn on 启用 Flash Attention，提升推理速度
--cache-type-k q8_0 K cache 量化格式
--cache-type-v q8_0 V cache 量化格式
--cache-ram 24576 RAM 中缓存大小（MB）
--slot-prompt-similarity 0.01 插槽相似度阈值，低值利于 cache 复用
--slots 启用插槽机制

Claude Code 关键参数

参数 作用
--exclude-dynamic-system-prompt-sections 将 cwd、env、memory、git status 从 system prompt 移到用户消息
--settings '{"includeGitInstructions":false}' 禁用内置 git 指令和 git status 快照
--dangerously-skip-permissions 绕过权限检查（本地沙箱环境使用）
--bare 最小化启动模式

原理

1
动态信息移出 --exclude-dynamic-system-prompt-sections 将每机器相关的动态信息移出 system prompt
2
Git 指令禁用 --settings 移除内置 git 指令，进一步减少动态内容
3
Cache 复用 两者结合确保 system prompt 在多次请求间保持稳定，llama-server 可命中 KV cache

测试结果

✓
首次请求 prompt eval time = 271,184.95 ms / 34,947 tokens
✓
后续请求 prompt eval time = 5,136.44 ms / 441 tokens（降低 98.7%）

✓

✓
生成单文件 HTML 游戏 正常

配置要点总结

  • 使用 --exclude-dynamic-system-prompt-sections
  • 使用 --settings '{"includeGitInstructions":false}'
  • 配置 llama-server 的 cache 参数和 slot 机制
  • 验证日志中出现 restored context checkpoint
